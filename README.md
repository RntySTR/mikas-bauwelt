# Mikas Bauwelt

3D-Bauspiel mit Klemmbausteinen für das iPad: bauen, Landschaft formen, mit eigener Figur laufen, Autos und Flugzeuge bauen, fahren und fliegen.

Spielen: https://rntystr.github.io/mikas-bauwelt/ – auf dem iPad in Safari öffnen, dann Teilen → „Zum Home-Bildschirm“.

Gespeichert wird auf dem Gerät und in Firebase Firestore (Projekt mikas-fussballquiz, Sammlung `bauwelt`). Den Zugang zu den eigenen Bauwerken öffnet der Speicher-Code in den Einstellungen.
